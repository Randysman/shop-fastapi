# Shop FastAPI

A full-stack e-commerce application built with **FastAPI** and **Vue.js**.

## Features

- Product catalog
- Categories
- Shopping cart
- REST API
- Repository & Service pattern
- PostgreSQL
- Docker support

## Tech Stack

### Backend

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- PostgreSQL

### Frontend

- Vue 3
- Vite
- Vue Router
- Pinia

### DevOps

- Docker
- Docker Compose

## Installation

```bash
git clone https://github.com/Randysman/shop-fastapi.git
cd shop-fastapi

docker-compose up --build
```

Or run the backend and frontend separately.

### Backend

```bash
cd backend

pip install -r requirements.txt

python start.py
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
